# Чиллипирик — стартовый прототип

Это первый запускаемый каркас проекта: главная страница, создание приватной комнаты, вход по ссылке, лимит 5 участников, общий чат и базовая синхронизация YouTube-плеера.

## Запуск локально

Требуется Node.js 18 или новее.

```bash
npm install
npm start
```

Откройте http://localhost:3000 в браузере. Для проверки комнаты откройте ссылку в нескольких вкладках или на разных устройствах в одной сети.

## Что уже заложено

- Русскоязычный тёмный интерфейс; голубой акцент выбран временно, так как цвет ещё не был отдельно утверждён.
- Создание случайной комнаты и вход по ссылке без регистрации.
- Никнейм при входе.
- Максимум 5 подключённых участников.
- Комната удаляется после отключения последнего сокета.
- Общий чат с текстом и эмодзи.
- Добавление и замена YouTube-видео; новое видео не запускается автоматически.
- Серверная рассылка команд плеера.
- Переключатели камеры и микрофона с запросом разрешений браузера.

## Важные ограничения прототипа

Это не готовый публичный production-сервис. Перед реальным запуском нужно доработать:
1. **Видеосвязь.** Сейчас есть только интерфейсные плитки и запрос разрешений. Для передачи камеры/звука между людьми нужно реализовать WebRTC mesh с обменом offer/answer/ICE, TURN-сервером и обработкой переподключений. При 5 участниках mesh может быть тяжёлым для мобильных устройств; стоит оценить SFU (например, mediasoup/LiveKit).
2. **Восстановление участника.** Сейчас обновление страницы создаёт новое Socket.IO-подключение. Нужен отдельный подписанный токен участника с ограниченным сроком жизни и механизмом безопасного восстановления.
3. **Синхронизация плеера.** Сейчас заложен базовый обмен состоянием. Нужны тесты дрейфа времени, блокировка эхо-команд, обработка seek/buffer/error и адаптеры для других хостингов. YouTube API не гарантирует управление всеми параметрами качества.
4. **Безопасность и устойчивость.** Нужны rate limiting, валидация/ограничение сообщений, защита от спама, логирование, graceful shutdown и тесты.
5. **Масштабирование.** Для нескольких серверов потребуется Redis adapter и внешнее хранилище состояния комнат.
6. **HTTPS.** Камера/микрофон доступны в production только через HTTPS (кроме localhost).
7. **Внешние зависимости.** YouTube iframe API и Google Fonts загружаются с внешних доменов; доступность зависит от сети и региона.

## Структура

- `server.js` — Express + Socket.IO, комнаты и серверные события.
- `public/index.html` — интерфейс.
- `public/style.css` — адаптивная тёмная тема.
- `public/app.js` — клиентская логика.

Цвет, логотип и отдельные UX-детали можно уточнить до следующей итерации.
